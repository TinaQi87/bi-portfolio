# Module 8: Workflow Orchestration

## Overview

Data pipelines need to run automatically, on schedule, with proper dependency management. This module teaches you how to orchestrate workflows.

---

## Why Orchestration?

- Run pipelines automatically (not manually)
- Handle dependencies between tasks
- Retry failed tasks
- Monitor and alert on failures
- Scale to many pipelines
