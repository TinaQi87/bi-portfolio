# Module 10: Capstone Project

## 🎯 Project: StreamFlow Analytics Pipeline

Congratulations! You've learned all the skills needed to be a data engineer. Now it's time to put everything together in a real-world project.

---

## The Scenario

You've been hired as a Data Engineer at **StreamFlow**, a music streaming startup. They need you to build a complete data pipeline that:

1. Ingests listening data from multiple sources
2. Transforms and cleans the data
3. Loads it into a data warehouse
4. Enables analytics on user listening behavior

---

## What You'll Build

A production-ready ETL pipeline that demonstrates:

| Skill | Application |
|-------|-------------|
| Linux | Scripts, cron scheduling |
| SQL | Database design, queries |
| Python | ETL code, data processing |
| Data Modeling | Star schema design |
| ETL | Extract, transform, load |
| Data Quality | Validation, testing |
| Git | Version control |
| Orchestration | Scheduled pipeline |
| Performance | Optimized queries |
