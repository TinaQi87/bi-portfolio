# Module 7: Version Control with Git

## Overview

Every professional data engineer uses Git. It tracks changes to your code, lets you collaborate with teammates, and saves you when things go wrong.

---

## Why Git Matters for Data Engineers

- **Track changes**: See exactly what changed in your ETL pipeline and when
- **Collaborate**: Work on the same codebase without overwriting each other
- **Rollback**: Instantly revert to a working version when something breaks
- **Code review**: Get feedback before changes go to production
- **Audit trail**: Know who changed what and why
